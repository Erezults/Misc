מתחים ואספקה

◈

VPX Connectors

P0 — Power, IPMI, SYSRESET, 1PPS, Slot Addr, GPIO
P1 — Serial Ports, SYNC, SGMII, GLAN (MGR+MTU), LEDs
P2 — UARTs, Discretes, I2C, MDIO, 10GbE, Debug

אחסון ואבטחה

SSD via PCIe (GLS85LE1160)

SE051 × 2 + Tamper Inputs + Secure Erase

SE051 Secure Element

שני רכיבי SE051 (MGR + MTU)
כתובת I2C: 0x48
ממשק I2C ייעודי עם Reset
Reused from COBRA-RMSU

💾

אחסון מאובטח

NOR Flash נפרד ל-MGR ול-MTU
ממשק QSPI (4-bit)
FRAM CY15B102QN ב-MCU
SSD עם Hold-Up Capacitor

🛡

MCU STM32L443

UFBGA100-7x7mm
3× Tamper Inputs
SENS I2C × 3 + ADC + GPIO × 4
SPI to MTU interface
מתח: +1.8V_MCU

🔗

Secure Erase Chain

Secure_Erase_IN (VPX P2)
→ MGR / MTU (via MUX #9)
→ MCU: MCU_Secure_Erase_IN
→ RMSU: Secure_Erase_RMSU
→ Out: Secure_Erase_OUT (VPX P2)

🔧

BIT — Built-In Test

IO Expander (I2C ADD: 0110 A2 A1 A0)
7× Discrete Out + Loopback

⚠ שים לב — לוגיקה הפוכה:
BIT_DISC_OUT = '0' → BIT Enabled
BIT_DISC_OUT = '1' → BIT Not Active

שאלות פתוחות

נושאים הדורשים הבהרה

  • ?
    Debug Shorts — תוכנית הסרה: ה-Short על IPMI Bus B (עמ׳ 5) — האם מיועד רק לפרוטוטייפ? מה התהליך להסרה לפני ייצור סדרתי?
  • ?
    9V_ISO — הוסר לגמרי? ההערה "9V_ISO removed" מופיעה בעמ׳ 26-27 ליד Discrete Outputs, אך מעגל ה-9V ISO עדיין מוצג בעמ׳ 41. האם זה הוסר חלקית בלבד?
  • ?
    התנגשות כתובות PHY: שני ה-PHYs (MTU Port 1 ו-MGR Port 2) מוגדרים עם כתובת PHYAD = 0x3. האם ה-MDIO bus משותף? אם כן — יש התנגשות כתובות!
  • ?
    MUX #10 — מנגנון Fallback: MUX MTU #10 משמש לניתוב כל 6 ערוצי RS422 COM בין MGR ל-MTU. אם ה-MUX נתקע — כל התקשורת הטורית נפגעת. האם יש מנגנון גיבוי?
  • ?
    Power Sequencing: לא נמצאה הגדרה מפורשת של סדר הדלקת מתחים בשרטוט. האם יש מסמך נפרד? ה-FPGA וה-PHY דורשים סדר הדלקה מוגדר (Core → IO → Auxiliary).
